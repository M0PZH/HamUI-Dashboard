# hamui-dashboard

User-customisable, drag-and-drop dashboard for ham radio software, built on
[HamUI](https://github.com/M0PZH/HamUI). Users choose which widgets to show,
resize them (XS / S / M / L / XL) and rearrange them by dragging — with a mouse,
trackpad or touch screen.

This is an extension: it depends on HamUI but is not part of it.

Status: design in progress.
